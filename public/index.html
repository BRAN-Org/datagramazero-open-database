GET /api/v1/articles

Retorna a lista paginada de trabalhos científicos com suporte a múltiplos filtros facetados, ordenação configurável e busca textual global com normalização fonética e de acentuação.

Busca Textual e Filtros Combinados

O parâmetro q realiza busca insensível a acentos em título, resumo, autores e palavras-chave simultaneamente. Você também pode filtrar por múltiplos anos separando-os por vírgula (ex: ?year=2022,2024).

Parâmetros de Consulta (Query String)

ParâmetroTipoPadrãoDescrição & Exemplo
qstring—Busca textual global em título, resumo e autores (ex: cienciometria).
yearstring—Filtrar por ano/edição (ex: 2024 ou 2020,2022,2024).
authorstring—Filtrar por nome de autor (ex: Vanz).
toolstring—Filtrar por software metodológico (ex: VOSviewer, Bibliometrix).
sourcestring—Filtrar por fonte de dados utilizada (ex: Web of Science, SciELO).
stagestring—Filtrar por etapa metodológica (ex: Análise de Redes).
limitinteger20Registros por página. Passe 0 para exportação completa despaginada.
offsetinteger0Deslocamento inicial para paginação.
sortstringyearCampo de ordenação (year, title, doi).
orderstringdescDireção da ordenação (asc ou desc).

GET /api/v1/articles/:key

Recupera os detalhes completos de um artigo específico utilizando seu identificador unívoco. A consulta prioriza correspondência exata antes de recorrer a qualquer busca secundária.

Formatos de Identificador Aceitos

Você pode consultar passando o ID canônico (ex: ebbc-2022-441), o número do DOI (ex: 10.22477.01) ou o DOI completo com prefixo (ex: https://doi.org/10.22477.01, codificado na URL). Artigos de 2012–2016 sem DOI de origem devem ser consultados pelo ID canônico e retornam rigorosamente doi: "N/A".

Parâmetros de Rota (Path)

ParâmetroTipoObrigatórioDescrição
keystringSimID estruturado canônico (ex: ebbc-2022-441) ou DOI registrado na origem.

Respostas HTTP

CódigoCondiçãoPayload
200 OKArtigo localizadoObjeto completo do artigo com 100% dos metadados, links de PDF e URL oficial.
404 Not FoundChave não encontrada{"error": "Registro com a chave '...' não encontrado."}
GET /api/v1/articles/export

Exporta o acervo integral ou subconjuntos filtrados nos 4 principais formatos padronizados para pesquisa científica, cienciometria e ciência de dados.

Extração Massiva Despaginada

O endpoint de exportação não impõe cortes artificiais. Ao omitir limit ou passar limit=0, 100% dos registros correspondentes aos seus filtros serão exportados no fluxo de resposta.

Formatos Suportados (?format=)

FormatoExtensãoContent-TypeAplicações & Diferenciais
json .json application/json Array JSON plano com todos os campos estruturados para ingestão em Python (pandas), NoSQL e pipelines.
csv .csv text/csv; charset=utf-8 Planilha com UTF-8 BOM para abertura nativa e sem distorção de acentuação no Excel, SPSS, LibreOffice e R.
bibtex ou bib .bib application/x-bibtex Entradas @inproceedings com campos url e eprint (link direto para PDF) para LaTeX, Overleaf e Zotero.
ris .ris application/x-research-info-systems Registros TY - CONF com tags L1 (anexo PDF direto) e UR para VOSviewer, Mendeley, EndNote e Bibliometrix (R).

Exemplo de Comando cURL para Download

# Baixar acervo completo em RIS para o VOSviewer
curl -s -L "https://ebbc-open-database.vercel.app/api/v1/articles/export?format=ris" -o ebbc_acervo.ris

# Baixar apenas trabalhos de 2024 em CSV para Excel
curl -s -L "https://ebbc-open-database.vercel.app/api/v1/articles/export?format=csv&year=2024" -o ebbc_2024.csv
GET /api/v1/articles/stats

Retorna indicadores quantitativos agregados em tempo real sobre todo o acervo, incluindo volumetria de autores únicos, rankings das ferramentas mais utilizadas e séries históricas por edição.

Estrutura do Objeto Retornado

ChaveTipoDescrição
totalRecordsintegerTotal de artigos catalogados na base de dados (808).
metricsobjectTotais de autores únicos, ferramentas distintas e fontes mapeadas.
topListsobjectRankings top-10 de Softwares (topTools), Fontes (topSources), Autores e Palavras-chave.
breakdownsobjectDistribuição anual (yearDistribution) e por etapas metodológicas (stageBreakdown).
GET /api/v1/articles/stats/correlations

Calcula a matriz de coocorrência bidimensional entre duas variáveis metodológicas curadas (ex: Softwares x Fontes de Dados) para construção de redes cienciométricas e mapas de calor (heatmaps).

Parâmetros de Consulta

ParâmetroTipoPadrãoDescrição
fieldAstringtoolsPrimeiro eixo da matriz (ex: tools, data_sources).
fieldBstringdata_sourcesSegundo eixo da matriz.
limitinteger6Dimensão máxima N x N das categorias principais.
GET /api/v1/articles/stats/temporal

Calcula a proporção percentual relativa normalizada a 100% ano a ano das categorias selecionadas, permitindo analisar a evolução ou declínio de ferramentas ao longo do tempo.

Parâmetros de Consulta

ParâmetroTipoPadrãoDescrição
fieldstringtoolsDimensão analisada (ex: tools, data_sources).
limitinteger5Número de categorias com maior representatividade histórica.
GET /api/v1/articles/stats/pareto

Calcula as frequências absolutas e o percentual cumulativo de termos ou autores para testes empíricos de leis bibliométricas (Lei de Bradford, Lei de Lotka e Curva de Pareto 80/20).

Parâmetros de Consulta

ParâmetroTipoPadrãoDescrição
fieldstringauthorsCampo analisado (authors, keywords, tools).
limitinteger10Tamanho da amostra no topo do ranking.
GET /api/v1/articles/stats/scatter

Retorna pares de coordenadas (X, Y) agregados e os coeficientes da reta de regressão linear para gráficos de dispersão bibliométrica e correlação de variáveis.

GET /api/v1/config

Fornece a configuração institucional completa do acervo, esquemas de facetas configuradas, campos de ordenação e metadados de governança da BRAN Org.

FAIR DATA CERN Zenodo Archive & Full Raw Data

Preservação permanente e imutável de todos os artefatos originais e brutos da base no repositório CERN/Zenodo sob DOI permanente registrado.

O pacote completo arquivado no Zenodo inclui:

  • SQLite3 (banco relacional completo): esquema normalizado com todas as tabelas e índices para consultas analíticas SQL diretas offline.
  • CSV consolidado (UTF-8 com BOM): compatível imediatamente com Microsoft Excel, LibreOffice Calc, SPSS, R e Python (pandas).
  • JSON estruturado: exportação bruta do catálogo em lote para ingestão em pipelines de dados e NoSQL.
  • Textos completos em PDF: cópias digitais íntegras de todos os artigos do acervo para mineração textual (text mining) e NLP acadêmico.

RECEITAS Exemplos Práticos em Python & R

Scripts reproduzíveis para integrar a API diretamente em ambientes de pesquisa bibliométrica, ciência de dados e mineração de texto.

Python: Carregamento do Acervo em Pandas

import pandas as pd
import requests

# Baixar os 808 artigos despaginados
data = requests.get("https://ebbc-open-database.vercel.app/api/v1/articles/export?format=json").json()
df = pd.DataFrame(data)

print(f"Total: {len(df)} artigos | Período: {df['year'].min()} a {df['year'].max()}")
print(f"Artigos com PDF direto: {df['pdf_url'].notna().sum()}/{len(df)}")

R: Download em RIS para Análise no Bibliometrix

# Download direto do arquivo RIS compatível com bibliometrix
ris_url <- "https://ebbc-open-database.vercel.app/api/v1/articles/export?format=ris"
download.file(ris_url, destfile = "ebbc_acervo.ris", mode = "wb")

# Ingestão e análise
library(bibliometrix)
M <- convert2df(file = "ebbc_acervo.ris", dbsource = "isi", format = "ris")
results <- biblioAnalysis(M, sep = ";")
summary(results)

Terminal Bash: Extração de Links de PDFs via cURL + jq

# Extrair lista de IDs e URLs de PDFs de 2024
curl -s "https://ebbc-open-database.vercel.app/api/v1/articles/export?format=json&year=2024"   | jq -r '.[] | "\(.id) \(.pdf_url)"' > pdf_urls_2024.txt
